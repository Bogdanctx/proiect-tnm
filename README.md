# Tema proiectului
Cautarea intr-un labirint a echipamentelor necesare pentru derularea laboratorului de retele de calculatoare folosind sunete pentru a aprecia distanta fata de fiecare obiect cautat

# Tehnologii
Am folosit: Three.js si Pure Data (PD)

# Features
- Un toggle button la inceput care te lasa sa activezi/dezactivezi muzica de pe fundal
- Sistem de hint-uri daca ramai blocat in labirint: se apasa tasta space si pe radar va aparea pozitia obiectului si pozitia jucatorului
